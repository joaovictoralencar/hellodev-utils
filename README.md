# HelloDev Utils

Foundation utilities for HelloDev packages. Includes RuntimeScriptableObject base class, GameContext service container, IBootstrapInitializable interface, and extension methods for safe event handling.

## Installation

Add the package to Unity Package Manager -> Add package from Git URL:

$installUrl

(For a specific release, add #v1.0.1 to the URL after tagging a release.)

## Usage

Import into your project and follow the HelloDev docs.
